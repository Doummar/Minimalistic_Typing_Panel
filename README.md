# Minimalistic Typing Panel

A clean, distraction-free floating scratchpad for Anki.

Minimalistic Typing Panel lets you type notes, answers, or calculations directly during review without leaving your cards. Designed to stay lightweight and out of the way while improving focus and active recall.

Originally built for my own daily study sessions and later shared with the Anki community.

# Features

- Floating scratchpad
- Distraction-free typing
- Glassmorphic interface
- Transparent background
- Auto-clear text
- Lock typing on answer side
- Forward Anki shortcuts
- Custom toggle shortcut
- Draggable panel
- Lock position
- Adjustable font size
- Adjustable opacity
- Custom colours
- Center text alignment
- Light & Dark mode support

# Perfect For

- Language learning

# How It Works

1. Open the typing panel using your shortcut.
2. Type your answer or notes.
3. Reveal the card.
4. Grade using normal Anki shortcuts.
5. Continue reviewing without touching the mouse.

---

# Installation

Download from AnkiWeb or clone this repository and copy the add-on into your `addons21` folder.
